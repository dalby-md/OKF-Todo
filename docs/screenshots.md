## Your task workspace

Keep development and support work in one local workspace, with task notes, priorities, deadlines, and tags. No online account is required.

[![Task workspace with task views, a task list, and rich-text notes](images/screenshots/01-task-workspace.png)](images/screenshots/01-task-workspace.png)

## Focus on what needs action

Use **Act now** to find urgent and overdue work that is not waiting on someone else.

[![Act now view showing tasks that need attention](images/screenshots/02-focus-on-what-matters.png)](images/screenshots/02-focus-on-what-matters.png)

## Keep waiting work visible

See what is waiting, who or what you are waiting for, and the context behind each task.

[![Waiting tasks with their waiting details](images/screenshots/03-track-follow-ups.png)](images/screenshots/03-track-follow-ups.png)

## Keep the details together

Track checklist progress, attach supporting files, and follow comments and change history in the **Timeline**.

[![Task details showing a checklist, attachments, and Timeline](images/screenshots/04-keep-the-details-together.png)](images/screenshots/04-keep-the-details-together.png)

## Work in dark mode

Choose a light or dark theme to suit your workspace.

[![OKF Todo task workspace in dark mode](images/screenshots/05-work-in-dark-mode.png)](images/screenshots/05-work-in-dark-mode.png)

## Protect your local work

Create database backups and restore from a file. Before restoration, OKF Todo creates a safety backup of your current data.

[![Data settings with database backup and restore options](images/screenshots/06-protect-your-local-work.png)](images/screenshots/06-protect-your-local-work.png)

## Write in Markdown

Write task notes with Markdown source and a live preview side by side. Use headings, lists, quotations, and code snippets to keep investigation notes readable.

[![Markdown editor showing source alongside a live preview with headings, lists, and a code snippet](images/screenshots/07-write-with-markdown.png)](images/screenshots/07-write-with-markdown.png)
