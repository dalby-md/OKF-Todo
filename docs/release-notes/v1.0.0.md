# OKF Todo 1.0.0

OKF Todo 1.0.0 is the first stable release. It is packaged and tested for
Windows. macOS and Linux remain source-build targets without packaged
installers.

## Highlights

- Local-first desktop task management with lists, lifecycle views, rich task
  details, checklists, relationships, attachments, Timeline, Trash, and export.
- Offline Help for day-to-day use, the Open Knowledge Format context layer, and
  the built-in MCP server.
- A broad MCP task interface for approved read and write workflows from
  compatible AI assistants.
- Microsoft Store distribution and a signed Windows x64 Inno Setup installer.
- Light and dark themes, responsive layouts, persisted preferences, and a
  refreshed application icon.
- User-facing product name updated from **OKF-Todo** to **OKF Todo** while
  technical identifiers and existing data locations remain unchanged.

## Upgrade and data safety

The installer and Store package contain application files only. Installation,
upgrade, repair, and uninstallation never bundle, overwrite, move, or delete the
user SQLite database. Existing data remains under the user's local
application-data directory, and pending EF Core migrations are applied at
startup.

Back up important data before upgrading. Database downgrades are unsupported.

## Platform availability

- **Windows x64:** Microsoft Store and signed Inno Setup installer.
- **macOS and Linux:** source builds only; no packaged 1.0 installers.

## Known limitations

- The direct Windows installer does not provide automatic updates.
- macOS and Linux packaging and release verification are not complete.
