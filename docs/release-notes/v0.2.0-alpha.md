# OKF-Todo 0.2.0 alpha

OKF-Todo 0.2 remains evaluation software and a work in progress. Windows is
the primary packaged and tested platform.

## Highlights

- Adds Microsoft Store distribution alongside the direct Windows installer.
- Refreshes the application icon and Microsoft Store artwork.
- Expands the OKF and AI-assistant guidance for turning source material into
  useful, reviewable task artifacts.
- Improves project and Help links while keeping the application local-first and
  fully usable without an account or hosted service.

## Upgrade and data safety

The installer and Store package contain application files only. They never
bundle, overwrite, move, or delete the user SQLite database. Existing databases
remain under the user's local application-data directory, and pending EF Core
migrations are applied by the application at startup.

Back up important data before evaluating an alpha upgrade. Test upgrades with a
disposable copy of an existing database when possible.

## Direct installer warning

The GitHub-hosted Inno Setup installer for this alpha is not Authenticode
signed. Windows may show an unknown-publisher or Microsoft Defender SmartScreen
warning. Users who prefer a Microsoft-signed package should install OKF-Todo
from Microsoft Store.

## Current limitations

- macOS and Linux remain source-build targets without packaged installers.
- The direct Windows installer does not provide automatic updates.
- Database downgrades are unsupported.
