# OKF Todo 1.0.1

This maintenance release improves everyday task editing and navigation.

- Improved task-detail scrolling and window restoration on scaled displays.
- Clearer task actions, checklist labels, and view descriptions.
- Improved keyboard focus and Escape behavior in dialogs.
- Easier access to comments, Timeline filters, and hidden task details.
- Improved tag layout, task export options, Trash guidance, and offline Help.

The Microsoft Store package version is **1.0.1.0**. Existing task data remains
in the external local database; the package contains no user database.

Follow-up scheduling remains a design only and is not included in this release.
The existing local MCP interface remains available; these presentation changes
do not add new MCP operations.
