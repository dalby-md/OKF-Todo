# Triage labels

| Role and label | Meaning |
|---|---|
| `needs-triage` | Needs initial evaluation. |
| `needs-info` | Waiting for clarification or missing details. |
| `ready-for-agent` | Fully specified and suitable for agent implementation. |
| `ready-for-human` | Requires human implementation or judgment. |
| `wontfix` | Reviewed and deliberately declined. |

Use these exact label strings when a skill names a triage role.
The Git ownership rule in AGENTS.md applies in every state.
